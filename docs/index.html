SIMPLE ET DIRECT

Comment ça marche ?

Installez TUN-JOBS

Téléchargez l'application Android depuis les builds GitHub disponibles.

Créez votre espace

Inscrivez-vous et complétez votre profil selon votre parcours candidat ou employeur.

Explorez les possibilités

Consultez les offres, vérifiez leurs sources et utilisez les fonctions disponibles dans l'application.

🔐 Vos informations doivent rester protégées.

Les informations de profil, photos et CV sont des données personnelles. Les données privées ne doivent être accessibles qu'aux personnes autorisées selon les règles de l'application. Les offres provenant de portails externes doivent être vérifiées auprès de leur source. Consultez les autorisations et les informations affichées dans l'application avant de partager vos documents.
