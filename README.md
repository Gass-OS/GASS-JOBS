# GASS-JOBS

**GASS-JOBS** is a native Android employment platform starting with Kasserine and expanding across Tunisia.

## First MVP
- Browse job opportunities.
- Switch between job-seeker and employer journeys.
- View job details.
- Prepare candidate and recruiter profile flows.
- Build a debug APK automatically with GitHub Actions.

## Important
The current listings are clearly marked as demonstration data. No real applications, accounts, CV uploads, or personal contact details are collected yet. Those features require a secure backend, consent and privacy controls, and moderation.

## Build
Push to `main` or `feature/android-mvp`, or run the **GASS-JOBS Android APK** workflow manually. Download the `GASS-JOBS-Android-APK` artifact from the workflow run.

## Planned Tunisia sources
We will evaluate official public employment portals and government sources for permitted links, feeds, or APIs. Imported opportunities must retain their source and publication date; we will not present unverified listings as official.
