# TUN-JOBS

**TUN-JOBS** is the public-facing name of the GASS OS Android employment platform, starting with Kasserine and expanding across Tunisia.

## Website
The multilingual landing website is in `docs/` and is published with GitHub Pages through `.github/workflows/deploy-pages.yml`.

- French, English and Arabic (RTL) interface.
- Mobile-responsive landing page.
- Candidate and employer feature introductions.
- Links to the Android app releases, source repository and support issues.

After merging the website branch into `main`, enable **Settings → Pages → Build and deployment → Source: GitHub Actions**. The workflow will publish the site automatically. Expected URL: https://gass-os.github.io/GASS-JOBS/

## Android app
The native Android app connects job seekers and employers. Its first focus is Kasserine, with a nationwide Tunisia ambition.

## Data integrity and privacy
Any sample profile or opportunity shown in website illustrations is illustrative, not a live job listing. Real job listings must retain their source and publication date. Personal profile details, photos and CVs require secure backend storage, consent and clear visibility controls.
